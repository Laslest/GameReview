SAVEPOINT — PROJETO DE DESENVOLVIMENTO WEB

Como abrir:
1. Extraia a pasta do projeto.
2. Abra o arquivo index.html no navegador.
3. É necessário acesso à internet apenas para carregar o Bootstrap pelo CDN.

Páginas:
- index.html — página inicial
- noticias.html — notícias
- reviews.html — reviews com filtro em JavaScript
- sobre.html — descrição do projeto e tecnologias

Requisitos do enunciado atendidos:
- HTML, CSS, JavaScript e Bootstrap
- index.html + 3 páginas adicionais
- menu drop-down em “Categorias”
- layout responsivo

Interações em JavaScript:
- busca local na página
- filtro de reviews por plataforma
- botão “Carregar mais notícias”
- validação demonstrativa da newsletter
- atualização automática do ano no rodapé

Observação:
Os nomes de jogos, matérias e autores exibidos são fictícios e foram criados apenas para demonstrar o portal.
